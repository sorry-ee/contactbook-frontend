# 代码规范与协作约定

1. 前端使用语义化 HTML、原生 JavaScript；后端 Python 采用四空格缩进。沿用所在文件风格，不进行无关格式重写。
2. 命名表达用途；函数只承担明确职责；不为未要求的需求预留抽象。
3. 外部输入在后端校验；SQL 使用参数绑定；页面用户文本使用 textContent；不提交密钥、数据库、真实通讯录。
4. 两个仓库分别按功能建立分支，PR 说明改动与实际验证结果，评审后合并至 main。
5. Commit 使用 `feat:`、`fix:`、`test:`、`docs:` 等前缀；只记录实际完成的工作，不伪造作者或提交时间。
6. 新增数据处理逻辑补充对应测试；合并前执行后端测试和必要浏览器验证。
7. 每位成员使用自己的 GitHub 账号提交实际负责的代码。计划分工：成员A负责前端与交互，成员B负责后端与 Excel；计划贡献比例各50%，最终按真实完成情况确认。
